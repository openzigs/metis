# User Story: Order Tracking

> Original synthetic document authored for the METIS Domain Eval golden corpus (CC0-1.0).

## Overview

As a customer, I want to track orders so I know when to expect them.

## Requirements

- A customer must be able to view the current status of any order.
- A customer should see an estimated delivery date for each shipment.
- A customer may reorder a previous purchase with a single click.
