# User Story: In-App Messaging

> Original synthetic document authored for the METIS Domain Eval golden corpus (CC0-1.0).

## Overview

As a user, I want in-app messaging so I can reach support quickly.

## Requirements

- A user must be able to start a support conversation from any screen.
- A user should be able to attach a screenshot to a support message.
- The messaging surface must display delivery and read receipts for each message.
