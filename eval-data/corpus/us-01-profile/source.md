# User Story: Profile Editing

> Original synthetic document authored for the METIS Domain Eval golden corpus (CC0-1.0).

## Overview

As a member, I want to manage my profile so my information stays current.

## Requirements

- A member must be able to update their display name from the profile page.
- A member should be able to upload a profile avatar image.
- A member may optionally add pronouns that appear next to their name.
