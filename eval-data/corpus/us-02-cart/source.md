# User Story: Shopping Cart

> Original synthetic document authored for the METIS Domain Eval golden corpus (CC0-1.0).

## Overview

As a shopper, I want a reliable cart so I can purchase multiple items.

## Requirements

- A shopper must be able to add an item to the cart from the product page.
- A shopper must be able to update item quantities within the cart.
- A shopper should be able to save the cart for later viewing.
