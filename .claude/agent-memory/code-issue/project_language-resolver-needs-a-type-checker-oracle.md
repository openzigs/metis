For a parser/resolver over a real language, per-rule fixtures do not converge under mutation testing (three passes on #1104 each found new wrong-target survivors); pin soundness with an oracle — a checked-in corpus plus a snapshot from the language's own type checker — and assert "every bound target equals the oracle's".

On PR #1104 (#1071, Go calls bound by declared types) three implementers counted "32 of 32", "99 of 99" and "327 of 327" mutants killed, and three independent passes (65, 110, 295 mutants) each found new one-edit mutants in `parsers-tree-sitter-go.ts` / `go-type-resolution.ts` that bound a WRONG target with every suite green. The production code was right each time; the tests could not see it break.

**Why:** the surface is a language. A fixture per rule pins the rules somebody thought of, and the implementer's own mutants are drawn from the same list of rules as the tests.

**How to apply:**

- Corpus: `server/tests/fixtures/go-oracle/` — Go that compiles (`go vet` clean), several modules plus a no-`go.mod` GOPATH tree, a dependency reached through `replace`. Write a construct there to cover it.
- Oracle: `scripts/go-oracle-snapshot/main.go` (stdlib only: `go list` + `go/types`, three platforms) → `oracle.snapshot.json`, regenerated by `node scripts/gen-go-oracle-snapshot.mjs`. Never run by build, tests or CI; a corpus hash makes drift a failing test.
- Assert per call: bound-by-type target == oracle target (zero tolerance); decided verdicts agree in class, with an exact allow-list that fails when an entry goes stale; the walker's call edges match the oracle's call sites by `file:line:name`.
- Report recall as a checked-in list, and snapshot EVERY verdict beside the oracle's answer: a mutant that turns `interface` into `unknown` contradicts nothing and still changes behaviour.
- Give the comparison function positive controls (feed it a wrong binding; it must object).
- The first run of the oracle found real bugs no fixture had: a call through `var f = fn` bound to `fn`; test-file methods on embedded types; explicit generic instantiation `F[T](x)` recorded as no call at all (the grammar reads it as a conversion or an index).
- Run mutation in two stages: the corpus in-process (thousands of mutants in minutes), hand-written suites only for its survivors. Kill a hung mutant's real process, not a wrapper.
- When the oracle disagrees with the resolver, fix the resolver (when in doubt: undecided), never the snapshot.
