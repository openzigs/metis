The scrubber is `server/src/lib/ai/tool-runtime/fence-scrub.ts` (`scrubFenceLookalikes`):
fold a copy (NFKD, case, confusables, HTML references), match one fixed pattern on the copy,
splice the replacement into the ORIGINAL. Its table is generated by
`server/scripts/generate-fence-confusables.ts` into `fence-confusables.generated.ts`. Tests:
`server/tests/lib/ai/fence-scrub.test.ts`, `server/tests/analysis-prompts-fence-lookalikes-1114.test.ts`.

**Why:** each item below was a real bypass or a real hang found in review or by a probe.

**How to apply:**

- **A regex that opens with `X+` is quadratic on a long run of X** (the old `=+` fence
  pattern re-scanned the run from each start). Prefix `(?<!X)` and pin it with
  `server/tests/helpers/linear-time.ts`.
- **A redaction marker that ends in the fence's own delimiter can re-form a fence** with the
  leftovers of a chained match (a marker ending in `===`). Match the whole chain as one span,
  and test that a second scrub changes nothing (idempotence).
- **Detect-on-a-folded-copy, splice-into-the-original widens a match to whole code points.**
  A code point that folds to several units (U+2A74 folds to `::=`) can then rejoin raw text
  into an exact fence when the marker contains the fence token. Keep the replacement free of
  the token's characters (both callers use `[REDACTED-FENCE]`), and run the idempotence test
  with multi-unit folds.
- **Case fold, then confusables, then look the upper-cased result up AGAIN.** Lower-case
  Greek and Cyrillic homoglyphs reach a confusable only once upper-cased (Cyrillic small em
  to capital em). An exhaustive all-code-point closure check runs in seconds; prefer it to
  hand-picked samples.
- **Unicode `confusables.txt` lists sources, not prototypes.** A table built only from it
  misses the prototype itself (lower-case `l` for capital `I`). Add by hand every prototype
  that differs from the comparison character.
