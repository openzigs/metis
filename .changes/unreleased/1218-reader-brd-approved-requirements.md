section: Changed

- A reader-layout Business Requirements document (`DOCS_GEN_BRD_LAYOUT=reader`) now lists the
  approved requirements of the project's latest analysis run that has any, in its main part,
  under **Approved Requirements**: each one's
  id, title, description and acceptance criteria as approved and edited in METIS, with no model
  rewording. Requirements that do not fit are left out whole, with a note pointing to the full
  list. A project with no approved requirements still gets requirements reconstructed from the
  code.
