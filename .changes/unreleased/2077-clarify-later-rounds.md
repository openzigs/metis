- Clarifying questions now reach their second and third rounds. When you submit a round and
  questions are still open, the next round's questions are prepared and shown; the panel used
  to stay on the round you had answered. Opening the Questions tab no longer sends a request
  the server is bound to refuse: none for a viewer who cannot run analyses, and none for a run
  with no extracted requirements. Viewing complete questions no longer rewrites them each
  time. A company-policy question that points at "the retention rule" or a clause is now
  reworded like one that names a control id.
