- A change request's page has an **Impact and portfolio** card: **Run impact analysis** and
  **Run portfolio check** start from the change request with its requirements already filled
  in, and its results are listed there, newest first, each a link. **Options** opens the full
  form, pre-filled from it.
- The portfolio check can run before the requirements are approved; such a check is labelled
  **Run on unapproved requirements** on its page, in every list and in its export.
- The **Impact** and **Portfolio** steps show the state of the newest result and link to it. An
  impact analysis or portfolio check started from a change request links back to it.
