- You can now start a requirements review and pin a baseline from the UI. Before this, the
  Baselines page told you to approve a review that nothing could start. The Requirements page has
  **Request review**, which sends the latest analysis's requirements to the reviewers you choose.
  For review administrators, the Baselines page has **New baseline**, which pins the current
  version of every requirement in the project. The Baselines empty state now explains both options.
