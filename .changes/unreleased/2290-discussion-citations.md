- The AI's replies in a project discussion now have their citations checked, as chat answers do:
  each cited file, line range or excerpt number is checked against what that reply retrieved or
  read, and a **Citations** list under the reply marks the ones that did not check out. A verified
  citation of the project's code links to the file on GitHub. Everyone in the thread sees the list,
  live and after a reload.
