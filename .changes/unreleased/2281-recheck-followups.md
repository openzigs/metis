- **Re-check this requirement** is now offered for an edited requirement whose earlier wording
  produced no governing finding, so its new wording can be checked too. Re-checks are rate
  limited, and closing the page while one runs cancels it without storing anything. A deleted
  requirement's re-check results no longer show (with a raw id for a heading) in the Governing
  rules panel, the BRD or the chat, and no clarifying question is asked about them. The BRD
  labels re-checked wording "As re-checked" and no longer repeats the requirement's title.
