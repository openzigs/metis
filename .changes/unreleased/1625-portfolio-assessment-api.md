- The portfolio gap analysis has an API: start an assessment of a requirement
  statement, or of an existing requirement, across one product or every product
  you can access, follow it as a background job, read it back, list the ones for
  a product, and export it as Markdown. Anyone reading an assessment sees only
  the products and repos they can read now; the rest show as restricted.
