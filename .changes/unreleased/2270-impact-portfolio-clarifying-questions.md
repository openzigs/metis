- An Impact Analysis run on a document and a portfolio check on an FRD now ask clarifying
  questions about the document, in the same Clarifying Questions panel as Requirements Analysis.
  Each requirement the document reader found with loosely worded text (a vague term, an escape
  clause, an open-ended clause or a TBD) is listed on the result's page; Ask these questions runs
  the same classification and selection, asks only where the readings would build different
  things, and cites the paragraph with options. Answers are kept as the project's clarification
  answers: a later analysis or check of the project reuses them instead of asking again, and chat
  can cite them. Nothing is asked until you click. CSV export and import of the questions remain
  on Requirements Analysis only.
