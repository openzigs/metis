section: Changed
---

- The sidebar has six entries instead of twenty-one: Home, Projects, Chat, Activity, Library and Settings. Each opens a row of page tabs for the pages it now groups — Projects holds the cross-project Products, Documents, Repositories, Databases and Impact analyses views; Chat holds Chat and Workbench; Activity holds Tasks, Runs, Sessions, Scheduler and Reviews; Settings holds Settings, Vault, Eval and Admin.
- Every page keeps its address, so bookmarks and shared links still work, and the command palette (Ctrl+K / Cmd+K) finds any of them by name.
- The Admin tab is shown only to system admins. The Skills and Agents sidebar entries are gone; their addresses still lead to the admin Skills and Agents pages, and the Library still browses both.
