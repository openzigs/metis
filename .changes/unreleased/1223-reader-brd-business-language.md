section: Changed

- The main document of a reader-layout Business Requirements document now asks for business language: what the system does, for whom and why. Function names, file paths and database columns are left to the appendix, and sources stay as footnotes. METIS also checks each main section for code names and records what it found in the version's provenance, so reviewers can see it before sign-off.
