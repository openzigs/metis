- An end-to-end walkthrough run now produces two HTML slideshows from its screenshots: a
  tutorial on how to use METIS, and a run report with each step's Works and Useful scores, spend and linked
  issues. They are built with `node scripts/walkthrough/build-slideshow.mjs`, open offline,
  and can be printed to PDF.
