- A similar requirement on a requirement's card now offers "Start from these citations" to anyone
  who can edit the requirement. Before you confirm, it lists the code links it will copy and the
  ones it skips because they are out of date, never checked, or were borrowed themselves. Once
  copied, the links show in the requirement's code links as "Borrowed from REQ-xx, not yet
  checked by analysis", and a message says how many were copied and why any were skipped.
