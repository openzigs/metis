issue: 2225
section: Security
---

- Chat and discussion answers now respect document permissions. An excerpt from a document
  restricted to particular people or roles (for example generated documentation published for
  the person who generated it) no longer reaches the AI when someone else asks: not in a project
  chat, not through the chat's knowledge search, not in a discussion or Teams `@AI` reply. The
  same now holds for searching across projects and for the project retrieve API.
