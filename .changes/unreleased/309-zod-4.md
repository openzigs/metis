section: Changed

- Upgraded zod from 3 to 4. Validation status codes and error codes are
  unchanged, as are the friendly field messages (an omitted required choice
  field still reads "is required") and the tool schemas sent to model providers
  and MCP hosts. Datetime fields accept the same forms as before, including a
  time without seconds and a `+0100` offset. Some behaviour changed on purpose:
  integers above 2^53-1 are now rejected, and the default per-field text inside
  `details.issues` changed wording.
