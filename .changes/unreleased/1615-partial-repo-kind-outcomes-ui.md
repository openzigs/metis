- The verdict badge reads **Partly implemented** for a partly built requirement,
  and an unrecognised verdict shows a grey **Verdict unknown** badge. A code
  citation names the repository its `file:line` is in, when METIS knows it. Each
  requirement card shows its kind (functional or non-functional) and a **Kind**
  filter narrows the list. A multi-project impact analysis lists the projects with
  nothing to show in a collapsed group with the reason, such as **Checked: nothing
  affected** or **Not checked: no access**.
