- The Workbench Documents panel lists every document in the project instead of
  stopping at the first 50, so an upload in a large project can be attached
  again. A filter box narrows the list by name or path as you type, uploaded
  documents sit in their own group at the top, and each repository's files
  appear as a folder tree that starts collapsed. Repositories are named rather
  than labelled with an id suffix, and hovering a file shows its full path.
