---
issue: 424
section: Changed
---

- The Analysis page's findings filters (severity, category, agent and
  verification) are now part of the URL, together with the run, so a filtered
  view can be shared or bookmarked.
- "View requirement" after promoting a discussion message now opens the run
  that holds the new requirement, on the page of the Requirements tab where it
  is listed, scrolled to and highlighted. It previously opened the latest run
  on page 1.
- The Traceability tab explains why it is empty while a run is still in
  progress, or when a run did not complete, instead of showing a blank pane.
