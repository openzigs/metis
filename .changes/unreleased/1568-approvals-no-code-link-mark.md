- The Approvals tab now shows which requirements would be saved without a code link, before you
  approve them. Each such pending requirement is marked "No code link", and a line above the
  pending list gives the count. On a run started from ticked imported items these are usually the
  requirements the analysis added, because their evidence cites no code. Previously you only found
  out after approving.
