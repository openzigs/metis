- You can now edit a requirement on the Approvals tab before you approve it. A pending requirement
  has an **Edit** button that changes its title and description, and approving saves the
  requirement with your wording, still with the acceptance criteria and evidence the analysis
  wrote for it. Before this, the only way to correct a requirement was to approve it first and
  then edit it on the Requirements page.
