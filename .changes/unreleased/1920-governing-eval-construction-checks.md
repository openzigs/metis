- `eval:governing`: a metric an arm claims fixed by construction prints `n/a` only while every
  run measures the fixed value; a broken claim (a hard error, an ask or an unverified citation
  from A0) is judged and printed, marked `‡`. A non-finite or negative per-call estimate is
  refused before any call, since it would switch the dollar cap off or shrink its reserve. The
  past, `-ing` and `-ation` forms of a short subject word (logged, logging, taxation, keyed)
  now count as shared vocabulary. Each arm is compared with A0 on citation coverage as well
  as recall; no coverage bar is added, since one set after A0's baseline would be fitted to it.
