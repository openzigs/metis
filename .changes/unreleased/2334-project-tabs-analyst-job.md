- A project's tabs now follow an analyst's work: **Overview · Knowledge · Change requests ·
  Requirements · Deliverables · ⚙**. Knowledge holds Connections and Documents; Change requests holds
  Requirements Analysis, Import, Jira and Impact Analysis; Deliverables holds Documentation,
  Templates and Publish. The Code tab is gone: Code Overview, Pull Requests and Spec Kit are under
  ⚙, which is named "Project settings" for screen readers and as a tooltip. The Changes page is now
  **Compare analyses**, under Requirements, so it is not mistaken for a change request. Every page
  keeps its address, so bookmarks still work.
