issue: 2349
section: Changed
---

- Every project is now created with the same **New project** wizard, from the Projects page, the
  Projects card on Home (also once you have projects) and the command palette. The Projects page's
  separate Create form is gone. The wizard starts on **Documents only**, so you are asked for no
  repository or database you do not have, and its last step offers **New change request**, where
  you upload your documents, or the project's Overview.
- The project Overview is one numbered checklist for every project: **Add knowledge → Ready: ask a
  question → New change request → Review → Deliverable**, with **Publish** shown as optional. Each
  step names the project tab its action opens, and a project that already did the work shows those
  steps as done.
