- An analysis run is now a **change request** with a title. Start one with **New change
  request**: name it (or keep the proposed name, the first document's), choose or upload the
  documents or tick imported tracker items, and click **Run with defaults**; the agents, model and
  enhancement switches are behind **Options**. The change request is listed by title in the run
  list, the Documentation and Requirements run dropdowns, Publish and Reviews, with the run number
  and date after it. Its page shows what it was started from, the settings it ran with (saying
  when they were the defaults), a rename control, and an eight-step header (Read, Questions,
  Requirements, Policy check, Impact, Portfolio, Review, Hand-off) that says in words where each
  step stands and links to it. Runs made earlier get a title from their sources.
