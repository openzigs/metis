- An analysis run is now a **change request** with a title. Start one with **New change
  request** and **Run with defaults** (agents, model and switches are behind **Options**). Every
  run list shows the title, with the run number and date after it. Its page shows what it was
  started from, the settings it ran with, a rename control, and an eight-step header that says in
  words where each step stands, or "Unknown" when it could not be checked.
- Every run stores its title, so titles can be searched and sorted; earlier runs are named from
  their sources when the server starts.
