---
issue: 2506
section: Security
---

- An analysis you start now reads documents with your own access too: the document reader, document
  search (including the code agent's), the fallback to newly uploaded text and the default
  document choice include the restricted documents you can see. Anyone who can't see one of them
  sees what drew on it as "Restricted", and none of what rests on the run as a whole: its reviewed
  requirement list, web research, governing-rule applicability and findings, escalation and
  clarifying questions. They can't start, answer or import a clarification round on it, or decide
  or re-check one of its governing findings. You, and anyone with the same access, see everything.
  The notice now counts the restricted files and documents the analysis read, never which, and a
  run you start no longer says it left restricted sources out. Scheduled analyses still use only
  what everyone on the project can see.
  Clarification answers from a run that read a restricted source are kept on that run but are no
  longer added to the project's searchable knowledge. Generated documents use web research only
  from a run everyone on the project can see. The live capability event no longer names the
  documents an analysis read, on any run.
