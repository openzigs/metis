- The portfolio check can check a chosen set of requirements: tick requirements on a project's
  **Requirements** tab and click **Check N selected across portfolio**. Each is checked on its
  own, up to 100 in one check; a requirement's text past what one check reads is listed under
  **Not checked**. The requirements must be of one project, and only readers of that project
  can read the check. Choosing who builds it from the check's page re-opens the same set.
