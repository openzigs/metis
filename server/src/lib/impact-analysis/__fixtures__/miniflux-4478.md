# [Feature]: Mark all as read older than X

### Feature Summary

Mark all as read older than X

### What problem does this feature solve?

Right now you can either mark a page as read or mark everything as read. This gives people the option to just let things that are older than X days be marked as read. Common options would be 24 hours, 1 week, 1 month

### Proposed Solution

A dropdown on the mark as read for times. Times could be configured in settings.

### Alternatives Considered

I hear a tool called `miniflux-sanity` can do this but it'd be better in the UI
